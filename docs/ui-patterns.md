# DoNote UI 交互规范（弹层 / 提示 / 视觉）

> 本批（功能 + bug 修复批次）第 1 件事。**此后所有新功能都必须遵守本文**，
> 不要再出现「先随便做、回头统一」。细则里的数字都对应 `apps/web/src/styles/` 里已有的设计令牌，
> 写样式时用变量，不要写死 `px` / 颜色。

---

## 一、弹层：位置由**触发场景**决定

判据只有一条 —— **用户是在哪儿点的**。同一个动作在不同位置可以有不同形态（例如「重命名」在侧栏是贴着节点的弹层，在列表页是底部弹层），一致性看的是「场景 → 形态」这条映射，不是「每次都长一样」。

| 触发场景 | 形态 | 位置 | 现有实现 |
|---|---|---|---|
| 主内容区（列表页 / 详情页）里的行内操作 | **bottom sheet**（底部弹出） | 贴内容列底边，圆角只留上方 | `NoteActionMenu.vue`、`BatchToolbar.vue`、`SidebarTree.vue` 的行菜单 |
| 侧栏（树 / 导航）节点上的操作 | **context menu / popover**（贴着对象弹） | 贴在节点旁，空间不够就翻到另一侧 | 侧栏右键 / `⋯` 按钮（本批新增） |
| 顶栏 / 工具栏里的按钮 | **dropdown**（下拉） | 贴按钮下边，左对齐按钮左沿 | `EditorToolbar.vue` 的 `.popover`、`SlashMenu.vue` |

三条硬规则：

1. **主内容区的底部弹层居中于内容列，不是视口** —— `padding-left: var(--content-offset)`。
   按视口居中在窄窗口下会压到侧栏上。applies to 所有 fixed 浮层。
2. **侧栏里的弹层贴着对象，不铺满**。侧栏宽度可拖拽调整（默认 260px，范围 200–520px，
   手柄是右边界上那条 6px 窄带），宽度不定，所以余量要按**最窄的 200px** 算 ——
   真要放大面板（例如「移到…」的文件列表）就退回内容列的 bottom sheet，别在栏内硬塞。
3. **触屏没有右键**：任何右键菜单都必须同时给一个 `⋯` 按钮入口，两处走同一个动作表。

## 二、提示与通知：三档，按「要不要用户回应」选

| 形态 | 位置 | 时长 | 用在哪 | 实现 |
|---|---|---|---|---|
| **轻提示 toast** | 内容列底部居中（`bottom: 96px`） | 2–3 秒自动消失 | 做完了、做失败了、被拒绝了 —— 不需要回应的结果 | `stores/ui.ts` 的 `ui.toast()` + `App.vue` 的 `.toast` |
| **警示弹窗 alert / confirm** | 屏幕（内容列）居中 + 遮罩 | 等用户点 | 不可逆动作、需要二选一 | `AppDialog.vue` |
| **提示条 inline** | 内容区顶部或底部，随内容流 | 常驻到状态改变 | 持续存在的状态（缓存降级、冲突待处理） | `SettingsView.vue` 的 `.hint` / `.conflicts` |

- **一次只显示一条 toast**，新消息顶掉旧的（`ui.ts` 已这么做）。不要为并列消息加队列。
- 文案写**发生了什么**，不写「操作成功」这类空话：`已导入 3 篇笔记、2 个文件夹` > `操作成功`。
- 危险动作的二次确认文案必须说清后果与可逆性，见下。

### 危险动作的确认文案模板

```
删除文件夹：将删除 X 个子项（含 Y 篇笔记），全部进入回收站。确定？
解散文件夹：解散后内容会上移到上一级，文件夹消失。确定？
删除笔记：  笔记将进入回收站，30 天内可恢复。确定？
彻底删除：  「标题」将被从你的网盘里永久删除，无法恢复。
```

## 三、视觉参数

所有弹层一律用同一个材质，不再各写一套：

| 项 | 值 | 令牌 |
|---|---|---|
| 毛玻璃 | `backdrop-filter: blur(20px) saturate(180%)` | `--glass-blur` / `--glass-saturation`（低端设备由 `--glass-blur:0` 自动降级） |
| 背景 | 亮 `rgba(255,255,255,.66)`／暗 `rgba(20,26,42,.62)` | `--glass-bg` |
| 边框 | 1px 微妙高光 | `--glass-border` ＋ `.glass::before` 对角高光层 |
| 圆角 | 弹层本体 16px；贴底的面板只留上方 24px | `--r-md` / `--r-xl` |
| 阴影 | 跟随主题 | `--shadow-3`（浮层）/ `--glass-shadow` |
| 入场动画 | 300ms 弹簧曲线 `cubic-bezier(.34,1.56,.64,1)` | `--dur` + `--ease-spring` |
| 遮罩 | 铺满视口的一律 `rgba(0,0,0,.38–.42)`，不加 blur（除移动端抽屉） | — |
| 例外 | **贴节点的 popover 不铺遮罩**，改成「点在外面就关」（`pointerdown` 捕获 + Esc + 滚动 + resize） —— 压暗背景会把用户正要点的那一行盖住 | `SidebarTree.vue` |
| 主题 | 两套配色只覆盖颜色，结构不动 | `html[data-theme='light'|'dark']` |

**直接复用 `.glass` 类**（`styles/glass.css`）就能拿到上面这一整行，不要重写。

### z-index 阶梯（改前先看这张表）

浮层高度是**全局资源**，加新浮层前先确认插在哪一级：

| 层级 | 用途 |
|---|---|
| 1–6 | 页面内自层（卡片高光、顶栏 5、底栏 6、悬浮按钮 7） |
| 12–16 | 编辑器内浮层（工具栏下拉 12、块手柄 14/15、浮条与斜杠菜单 16） |
| 19 | 移动端抽屉遮罩 |
| 20 | 侧栏本体 |
| 21 | 行内动作菜单 / 批量条 / 侧栏行菜单 / **底部弹层** |
| 22 | `AppDialog`，以及与它等价的**编辑类 Modal**（全屏遮罩 + 单个面板，例：`MermaidPanel`） |
| 30–31 | 拖放遮罩与进度、全局 toast |

规则：**新浮层从 21 起找空位**。22 只留给「遮罩 + 单个面板」的模态（警示对话框与编辑面板），
不要给菜单 / 弹层用 —— 用到 22 以上之后，弹层里的操作就再也开不出确认框（对话框盖不住它），
只能靠「先关弹层再开对话框」绕。菜单里要再开一个对话框时，**先关菜单再开对话框**
（每次先 `menuTarget = null`），不要指望 22 能盖住 21 还保留菜单状态。

### 底部弹层（bottom sheet）只有一份实现

`.sheet-mask` / `.sheet` / `.sheet-title` / `.sheet-lock` / `.sheet-item` 与 `sheet-*` 入场动画
**全部在 `styles/app.css`**，`z-index: 21`。四个使用方（`NoteActionMenu`、`TrashView`、
`FoldersView`、`NoteEditView`）只保留各自独有的内容样式，并用统一的 `<Transition name="sheet">`
包住遮罩。不要再往组件里抄一遍 —— 之前抄了四份，z-index 还抄出了 21 和 25 两个值。

## 五、写新功能时的检查清单

1. 弹层位置是不是按**触发场景**选的（内容区 → bottom sheet｜侧栏 → 贴节点｜工具栏 → dropdown）？
2. fixed 浮层有没有 `padding-left: var(--content-offset)`（居中于内容列）？
3. 有没有复用 `.glass`，还是又手写了一遍 blur / 圆角 / 阴影？
4. z-index 取的是阶梯里的空位，还是随手写的数字？
5. 需要用户回应的用 `AppDialog`，不需要的用 toast —— 有没有反过来？
6. 危险动作的确认文案有没有说清「后果 + 可逆性 + 影响范围」？
7. 触屏上有没有等价入口（右键菜单必须配 `⋯`）？
8. 暗 / 亮两套主题都看过了吗（颜色一律走令牌，不写死）？
9. **页面读了路由参数 / query，参数变了会不会重取？** `/notes/:id`、`/folders/:id` 这类**同一条路由记录**在参数变化时组件是被复用的，`onMounted` 只跑一次、`const id = route.params.id` 只会取一次那个值 —— 必须 `watch` 参数（已处理：`NoteEditView` / `FolderDetailView` / `HomeView` 的 `q`、`tag`）。改名换 id 的那种要排除掉，别把编辑器重建。回归锁在 stage7 的「换笔记 / 换文件夹」两组断言。
10. **「已经开着 A，再打开 B」这条路径单独走过吗？** 列表页进详情是另一次挂载，**永远不会**暴露第 9 条那种缺陷；真正的入口是侧栏树（同一个驻留组件里点另一个链接）。
11. **页面级骨架别让整页滚（`styles/app.css`）**：`.page` 是 `height:100%` 的 flex 列、顶栏 `flex:none`，
    真正的滚动容器是 `.page-body`。整页滚时滚动条属于文档，会从窗口最顶端一路盖到标题栏的
    最小化 / 最大化 / 关闭那一条上。内容列居中由 `.page-body` 的左右 padding 承担
    （`--content-pad`，按改前 `max-width` + `margin:auto` 的 border box 几何反推）。
