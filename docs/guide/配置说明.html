DoNote 配置说明

这一页说清楚：笔记存在哪、怎么连、连不上怎么查。全文不需要懂技术，照抄字面就行。

一、先选一种用法

用法适合什么情况代价
本地模式 只有这一台电脑用，不想注册任何网盘、不想把笔记放到别人服务器上 换电脑要自己拷文件夹；两台电脑同时写不会自动合并
网盘模式（WebDAV） 几台设备都要看同一批笔记；或者想要一份放在自己网盘里的备份 要准备一个 WebDAV 地址和账号（坚果云、自己的 NAS 都行）
两种模式**随时可以切换**：设置 → 最下面那个按钮退出，回到登录页重新选。已经写下的笔记不会因为切换被删掉， 但两种模式的笔记是**分开存**的（本地归本地，网盘归网盘），切过去看不到另一边的笔记。

二、本地模式（什么都不用配）

  1. 打开 DoNote，在登录页最下面点 「只用本地，不同步」。
  2. 直接进列表页，右上角「新建笔记」就能写。
  3. 想知道笔记在哪：设置 → 本地笔记 → 位置，那一行就是完整路径；桌面版旁边有 「打开这个文件夹」，点一下就在资源管理器里打开。

笔记放在哪

装的哪种位置
绿色版（解压即用）<解压目录>\data\notes —— 整个文件夹拷走就带走了全部笔记
安装版文档\DoNote（即 C:\Users\你的用户名\Documents\DoNote）
上面两处都写不进退回 %APPDATA%\DoNote\notes，设置页会写一句「预期位置不可写，已回落」

笔记就是普通的 .md 文本文件，可以直接用记事本、VS Code 打开；备份就是把整个文件夹复制一份。

为什么安装版不放程序安装目录：卸载程序会把安装目录一起删掉，笔记会跟着没； 另外安装时如果改了目录，新装的会读不到旧目录里的笔记。放在「文档」下面，卸载不动它，也能自己找到。

三、网盘模式 · 坚果云（最省事）

  1. 注册并登录坚果云网页版（jianguoyun.com）。
  2. 右上角头像 → 账户信息 → 左侧 安全选项 → 第三方应用管理 → 添加应用密码。
  3. 名称随便填（例如 DoNote），点生成，复制那串 16 位密码。
  4. 回到 DoNote 登录页，按下表填：
栏目填什么
服务器地址https://dav.jianguoyun.com/dav（默认已填好）
账号坚果云的注册邮箱
密码刚才生成的应用密码，不是你登录坚果云的密码

点「连接」。第一次连会自动在网盘里建一个 DoNote 文件夹，笔记都存在这里。

坚果云开了微信二次验证的话，WebDAV 会连不上，先在安全选项里关掉。 免费版有流量额度（上传 1GB / 下载 3GB 每月），日常记笔记够用。

四、网盘模式 · 群晖 NAS

  1. DSM → 套件中心，安装 WebDAV Server。
  2. 打开它，勾选 启用 HTTP（内网够用）或 启用 HTTPS，端口默认 5005 / 5006，应用。
  3. 在 控制面板 → 用户与群组 里确认这个账号对目标共享文件夹有读写权限。
  4. DoNote 里填：
栏目填什么
服务器地址http://192.168.1.x:5005（把 IP 换成 NAS 的地址；开了 HTTPS 就是 https://…:5006）
账号 / 密码DSM 的登录账号与密码

连上之后 DoNote 会在根目录建 /DoNote。想换到某个共享文件夹里，可以先用文件管理器建好再指定。

五、网盘模式 · 威联通 NAS

  1. App Center 安装 WebDAV（QTS 里叫 Web Server 的一部分）。
  2. 控制台 → 应用服务 → Web 服务器，启用 WebDAV，端口默认 8081（HTTP）/ 8080（HTTPS）。
  3. DoNote 里服务器地址填 http://192.168.1.x:8081，账号密码用 NAS 的。

六、网盘模式 · 用一台 Windows 电脑当盘

Windows 自带的「共享文件夹」是 SMB 协议，DoNote 不支持；要在那台电脑上跑一个 WebDAV 服务。最省事的是 dufs（单文件，免安装）：

  1. 在 github.com/sigoden/dufs/releases 下载 dufs-x86_64-pc-windows-msvc.exe。
  2. 把它放到你要共享的文件夹里，同一层打开命令行，执行：
dufs.exe -A --allow-all --enable-webdav -p 5005
  • -A 用当前目录当根；--allow-all 允许上传 / 删除；--enable-webdav 就是 WebDAV。
  • DoNote 里服务器地址填 http://那台电脑的IP:5005。没有账号密码也可以连（内网自用够）。
  • 想开机自启：把这个命令行写成 .bat，放进「启动」文件夹。
也可以用 rclone serve webdav D:\笔记 --addr 0.0.0.0:5005，效果一样，还能顺带把别的网盘挂出来。

七、网盘模式 · 软路由 / 树莓派 / 小主机

Linux 上同样跑 dufs 或 rclone，换个系统而已：

./dufs -A --allow-all --enable-webdav -p 5005
# 或
rclone serve webdav /srv/notes --addr 0.0.0.0:5005

想用系统自带的 Apache / Nginx 也行，开 mod_dav 指向一个目录即可。

八、不在家也想同步

别做路由器端口映射（明文暴露到公网不安全）。装 Tailscale 更省事：

  1. NAS / 电脑和笔记本上都装 Tailscale，登录同一个账号。
  2. 在 Tailscale 后台看到那台机器的 100.x.x.x 地址。
  3. DoNote 的服务器地址把 192.168.1.x 换成 100.x.x.x，其他不变。

这样两台机器在一个虚拟内网里，出门也能连，不用碰路由器。

九、连不上怎么查

现象原因与做法
提示「账号或密码不对」 坚果云八成是填了登录密码 —— 要用应用密码。其他服务确认账号没写错、开了二次验证的先关掉。
提示「连接失败 / 无法访问」 地址写错或机器不在线：先用浏览器打开 http://地址:端口 看有没有反应；内网地址只在家里能用，出门见第八节。
能连上但看不到文件 / 提示无权限 账号对那个目录没有读写权限（群晖最常见），去 NAS 的共享文件夹权限里给上。
网页版连内网地址失败，桌面版可以 浏览器不允许 HTTPS 页面请求 http:// 内网地址。用桌面版，或者给服务端配上 HTTPS。
用一会儿提示「请求太多」 坚果云免费版 600 次 / 30 分钟。等半小时自动恢复；设置页能看到最近用掉了多少次。
两台机器改同一篇，谁赢 后保存的覆盖前面的，另一台会提示「云端比本地新」，让你选保留哪一版。

十、安全与边界

  • 账号密码只存在这台电脑上：Windows 凭据管理器里，不写进任何文件，也不上传。
  • 本地模式不联网：除了检查更新，DoNote 不会向外发任何请求。
  • 卸载：安装版不会删「文档\DoNote」里的笔记；绿色版删了解压目录才会删。
  • 备份：网盘模式 —— 网盘里那批文件就是原文；本地模式 —— 复制设置页显示的那个文件夹。

配置入口都在「设置」页；这一份说明在安装目录里也有一份（DoNote-配置说明.pdf）。
