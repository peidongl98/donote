# 美元符号边界

加了公式解析后，普通文本里的 `$` 不能被误当成公式定界符。

## 单个美元符号

这件商品售价 $100，那件 $200。

成本 $5 元，利润 $2 元。

## 连续两个美元符号但不是公式

价格从 $10 涨到 $20，涨幅 100%。

美元符号 \$ 单独出现。

## 真正的行内公式（应该被识别）

圆的面积是 $S = \pi r^2$，周长是 $C = 2\pi r$。

## 货币与公式混排

一件 $3$ 元，两件 $3 + 3 = 6$ 元。

## 代码里的美元符号

行内代码 `$HOME` 与 `$PATH` 不能被当成公式。

```
$ npm install
$ echo $SHELL
```

## 表格里的美元符号

| 项目 | 价格   |
| -- | ---- |
| 甲  | \$10 |
| 乙  | \$20 |
